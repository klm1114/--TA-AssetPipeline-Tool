# TA-AssetPipeline-Tool 使用说明

本文档面向第一次使用本工具的人，包含环境要求、安装步骤、使用方法、注意事项和常见问题。

---

## 一、环境要求

| 端      | 版本要求                                      | 说明                         |
| ------- | --------------------------------------------- | ---------------------------- |
| Blender | 3.0 及以上（已在 5.1 测试通过）               | 需要官方版，不支持某些魔改版 |
| Unity   | 2019.4 LTS 及以上（已在 [你的版本] 测试通过） | 需要能使用 Editor Scripting  |

---

## 二、Blender 端安装

1. 打开 Blender。
2. 顶部菜单 → **Edit → Preferences → Add-ons**。
3. 右上角点 **Install...**，选择 `01_Blender_Plugin/TA_Export_Tool.zip`。
4. 安装完成后，在搜索框里输入 "TA"，找到 **"TA 导出质检工具"**，**勾选前面的复选框**启用它。
5. 回到 3D 视图，按 **N** 键打开侧边栏，在竖排标签里找到 **"TA工具"** 标签页。

> ⚠️ 如果安装时报错 "Missing manifest"，通常是 zip 打包时多套了一层文件夹，或者 `__init__.py` 实际是 `__init__.py.txt`。请参考 README 中的打包说明重新打包。

## 三、Blender 端使用

### ① 命名规范检查

1. 在 3D 视图中选中要检查的物体（可多选）。
2. 展开 **① 命名规范检查**。
3. 在 **"允许的特殊字符"** 输入框里填允许的标点符号，可填 1 个或多个：
   - 只填 `_` → 只允许下划线
   - 填 `_.-` → 允许下划线、点号、短横线
   - 字母和数字始终允许，不用填
4. 点击 **"执行检查"**。
5. 结果会通过 Blender 界面底部的信息栏和系统控制台输出（Window → Toggle System Console 打开）。
6. 命名不规范的物体会一次性列出所有非法字符，例如：
   ```
   ❌ Rock@Large#01 —— 包含不允许的字符：@, #
   ```

### ② 清理未使用材质槽

1. 选中要清理的物体（可多选）。
2. 展开 **② 材质清理**。
3. 点击 **"清理未使用材质槽"**。
4. 结果会显示移除了多少个未使用的槽。
5. **这个操作不会删除正在使用的材质**，只会移除没有被任何面引用的冗余槽位，可放心使用。

### ③ Unity 规范导出

1. 选中要导出的物体。
   - **散件导出**：直接选中若干网格，每个网格会独立导出（不推荐用于场景模型）。
   - **场景整体导出（推荐）**：选中一个 Empty 作为根，网格都挂在它下面；或者直接选中所有平级网格，由工具自动创建临时根。
2. 展开 **③ Unity 规范导出**。
3. 设置 **"导出路径"**（点右侧按钮选择文件夹）。
4. 在 **"整体模型名称"** 里填写导出后的 FBX 文件名和 Unity 根节点名，例如 `Scene_Level01`。
   - 留空则自动使用根物体的名字。
5. 按需勾选 **"导出动画"**：
   - 静态模型 → 不勾选
   - 骨骼模型无动画 → 不勾选
   - 骨骼模型带动画 → 勾选
6. 点击 **"导出到 Unity"**。
7. 导出成功后，目标文件夹会出现 `<整体模型名称>.fbx`。

**导出时的自动处理：**
- 轴向自动修正为 Unity 规范（-Z Forward, Y Up）
- 缩放/旋转自动烘焙（Bake Space Transform）
- 保留层级结构，Unity 中可展开单独控制子结构
- 如果填了"整体模型名称"，工具会在导出时临时包裹一个 Empty，导出完成后自动恢复原场景，源文件结构不变

## 四、Unity 端安装

1. 把 `02_Unity_Tools/TA_Tools` 整个文件夹拖进 Unity 项目的 `Assets/` 目录下。
2. 等待 Unity 编译完成。
3. 编译成功后，菜单栏会多出一项 **Tools → TA工具**。

> ⚠️ `TA_Tools/Editor/` 文件夹的命名不能改。Unity 靠 `Editor` 这个文件夹名来判断哪些脚本只在编辑器里运行，改了就可能在打包时报错。

## 五、Unity 端使用

### ① FBX 自动剥离材质

**无需操作**。只要 `FBXMaterialStripper.cs` 存在于 `Editor/` 文件夹下，任何 FBX 拖入项目时都会自动把 Material Creation Mode 设为 None。

导入后，选中 FBX，看右侧 Inspector 里的 Materials 分页，Material Creation Mode 会显示为 None。

如果不想让某个 FBX 自动剥离材质，可以在 Inspector 里手动改回去（但下次重新导入时会被覆盖）。

### ② 命名规范检查

1. 在 Hierarchy 里选中要检查的物体（可多选）。
2. 打开 **Tools → TA工具 → TA 资产检查器**。
3. 展开 **① 命名规范检查**，设置"允许的特殊字符"。
4. 点击 **"检查命名"**。
5. 只有出问题的物体会打印在控制台，通过的不打印，末尾会有一句汇总。
6. **点击控制台里的红色报错，Hierarchy 会自动定位到对应物体**。

### ③ 材质完整性检查

1. 在 Hierarchy 里选中模型的根物体（比如整体模型名）。
2. 打开检查器窗口。
3. 点击 **② 材质完整性检查** 下的 **"检查材质"**。
4. 工具会递归遍历所有子结构，检查每个 Renderer 的材质槽。
5. 以下情况都会被视为"材质缺失"：
   - 完全没有材质槽
   - 某个材质槽是空的（`None`）
   - 只挂载了 Unity 自动补的 `Default-Material`（占位符）
6. 点击控制台的红色报错可定位到具体结构。

### ④ 一键全检

点击窗口底部的 **"一键全检（命名 + 材质）"**，会依次执行命名检查和材质检查，适合交接资产时快速过一遍。

## 六、常见问题

**Q1：Blender 里安装插件时报 "Missing manifest"？**
A：检查 zip 解压后的结构，应该是 `TA_Export_Tool/__init__.py`，或者直接是 `__init__.py`。不要多套一层文件夹。也要确认文件名不是 `__init__.py.txt`（Windows 默认隐藏扩展名容易踩坑）。

**Q2：导出 FBX 后，Unity 里根节点名不对？**
A：导出时要在 Blender 面板里填"整体模型名称"。留空时，工具会用选中列表里的第一个根物体命名，可能不是你想要的。

**Q3：Unity 里导入 FBX 后，材质球还是出现了？**
A：检查 `FBXMaterialStripper.cs` 是否放在 `Editor/` 文件夹下，并且脚本里 `materialImportMode = ModelImporterMaterialImportMode.None` 这行没有被误改。如果 Unity 版本太老（2018 之前），该 API 可能不存在。

**Q4：材质检查明明都上了材质，为什么还报"缺失"？**
A：如果你的材质是 Unity 内置的 `Default-Material`，会被识别为"占位符"并报警。需要手动挂一个真正的材质球（比如你自己创建的 `M_xxx`）。

**Q5：命名检查允许中文吗？**
A：目前不允许。工具只放行 ASCII 字母数字 + 你填的特殊字符。如果你的项目确实需要中文命名，可以修改脚本里的 `IsLegalChar` 方法，把 `c < 128` 的判断去掉。**但不推荐**，中文命名在引擎、版本控制、导出时都容易出问题。

**Q6：导出的 FBX 在 Unity 里缩放不对？**
A：确认 Blender 面板里没有改过导出参数（轴向、烘焙等都由脚本封装，面板上不暴露）。如果模型本身有非 1 的缩放，导出时会被烘焙进顶点数据，这是符合 Unity 规范的。
